# 兼容性矩阵

## Android 与功能

| Android | API | legacy APK | modern APK | 系统标准模拟 | 说明 |
| --- | ---: | --- | --- | --- | --- |
| Android 6 | 23 | 支持 | 不安装 | 支持 | 原版 Xposed 的主要适用版本 |
| Android 7～8.0 | 24～26 | 支持 | 不安装 | 支持 | legacy 配置共享依赖框架是否实现安全偏好通道 |
| Android 8.1～11 | 27～30 | 支持 | 支持 | 支持 | EdXposed、LSPosed/Vector legacy 或兼容 modern 框架按版本选择 |
| Android 12～16 | 31～36 | 支持 | 支持 | 支持 | Test Provider 使用 `ProviderProperties`；Mock 标记保留 |
| Android 17 | 37 | 支持安装与标准模式 | 支持安装 | 支持设计目标 | Xposed 模式还要求框架声明支持 Android 17 |

“支持”表示应用代码和构建配置覆盖该 API。厂商 ROM 可能改变开发者选项、后台策略和 Xposed 可用性，发布前仍需在目标 ROM 回归。

## Xposed 框架

| 框架类型 | 推荐 APK | 预期范围 | 配置通道 | 备注 |
| --- | --- | --- | --- | --- |
| 原版 Xposed | legacy | Android 6 | XSharedPreferences | Android 7/8 不承诺配置可读，改用标准模式或 New XSharedPreferences 框架 |
| EdXposed | legacy | 通常 Android 8～11 | New XSharedPreferences | FakeMap 必须加入作用域 |
| LSPosed legacy API | legacy | 以框架发行说明为准 | New XSharedPreferences | 原项目已停止维护的版本不承诺新系统 |
| Vector legacy API | legacy | 以框架发行说明为准 | New XSharedPreferences | 保留 API 89 入口 |
| libxposed API 101/102 | modern | Android 8.1+ | Xposed remote preferences | 需要 `PROP_CAP_REMOTE`，例如支持该 API 的 Vector 版本 |
| LSPatch 等变种 | legacy 优先 | 实验性 | 由变种实现决定 | 不作为正式兼容承诺 |

Vector 2.1 的发布说明声明完整支持 Android 8.1～17；使用前应同时核对最新版本及设备 ROM：[Vector releases](https://github.com/JingMatrix/Vector/releases)。

modern 服务 Binder 只接受 root 或 system UID，以阻止普通应用伪造框架服务。以普通应用 UID 运行的 rootless/embedded 变种即使仿真 API 102，也不会连接；这类环境应使用系统标准模式。

## 地图

| 场景 | Provider | 坐标交互 | 前置条件 |
| --- | --- | --- | --- |
| 中国大陆常规选点 | 高德 JS API 2.0（开发/BYO Key） | 显示 GCJ-02，保存 WGS-84 | Web Key + JS 安全密钥 + 合规额度；生产需安全代理 |
| 境外选点 | Leaflet + 栅格服务 | WGS-84 | HTTPS 瓦片、署名和许可链接 |
| 高德不可用 | 国际地图回退 | WGS-84 | 12 秒超时或初始化错误 |
| 离线 | 手工输入 | WGS-84 | 地图不缓存整区、不支持离线包 |

## 不支持的能力

- 隐藏 `Location.isMock()` 或旧版 Mock 标记；
- 修改开发者选项、AppOps 或替用户选择模拟位置应用；
- Wi-Fi、蜂窝、SIM、VPN、时区或语言伪装；
- GNSS/NMEA、卫星状态、传感器和原始测量伪造；
- 完整性验证、设备证明、游戏或风控绕过；
- 后台批量扫描、自动选择所有已安装应用；
- 未获授权的地图瓦片抓取或离线下载。
- Xposed 下直接改写 HMS、高德等厂商自定义 Location 对象。

## 建议回归矩阵

发布前至少覆盖：

- API 23、27、31、35、37；
- 中文与英文系统；
- 精确权限、近似权限、拒绝权限；
- 开始、重复开始、停止、进程终止和卸载前停止；
- 北京、深圳、海南、London、Kathmandu、Seoul 和边境坐标；
- 高德有效凭据、空凭据、错误凭据、超时和无网络；
- OSM 首张瓦片成功、403、连续 tile error、自定义署名链接；
- legacy New XSharedPreferences 与 modern remote preferences 更新；
- 原方法权限异常在 Xposed Hook 后仍原样抛出。
